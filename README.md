## 源代码

```cpp
// bubble_sort.cpp
// 功能：把 8 3 6 2 7 1 这六个数用「冒泡排序」从小到大排好序并输出。
// 说明：不使用 <algorithm> 里的 sort，冒泡排序的过程全部自己写，方便理解算法。
//
// 编译（MSVC）：cl /nologo /EHsc /utf-8 /std:c++17 /W4 bubble_sort.cpp
// 编译（GCC） ：g++ -std=c++17 -Wall -Wextra -o bubble_sort bubble_sort.cpp

#include <iostream>

// 交换两个整数
static void swapValue(int& a, int& b) {
    const int tmp = a;
    a = b;
    b = tmp;
}

// 冒泡排序（升序）：每一轮把「当前未排序部分的最大值」冒到后面
static void bubbleSort(int a[], int n) {
    // 外层循环：一共比较 n-1 轮
    for (int i = 0; i < n - 1; ++i) {
        bool swapped = false;  // 记录本轮有没有发生交换

        // 内层循环：在还没排好的前 n-1-i 个数里，两两比较相邻元素
        for (int j = 0; j + 1 < n - i; ++j) {
            // 升序要求「小的在前」：如果前一个比后一个大，就交换它们
            if (a[j] > a[j + 1]) {
                swapValue(a[j], a[j + 1]);
                swapped = true;
            }
        }

        // 本轮一次交换都没发生，说明已经有序，可以提前结束
        if (!swapped) {
            break;
        }

        // 打印每一轮的结果，方便观察排序过程
        std::cout << "第 " << (i + 1) << " 轮后：";
        for (int k = 0; k < n; ++k) {
            std::cout << a[k] << ' ';
        }
        std::cout << '\n';
    }
}

int main() {
    int a[] = {8, 3, 6, 2, 7, 1};
    const int n = static_cast<int>(sizeof(a) / sizeof(a[0]));

    std::cout << "排序前：";
    for (int i = 0; i < n; ++i) {
        std::cout << a[i] << ' ';
    }
    std::cout << '\n';

    bubbleSort(a, n);  // 调用冒泡排序，从小到大

    std::cout << "排序后：";
    for (int i = 0; i < n; ++i) {
        std::cout << a[i] << ' ';
    }
    std::cout << '\n';

    return 0;
}
```

## 1. 程序是怎么完成排序的

程序只做了三件事：准备数据、反复比较相邻两个数并交换、把结果打印出来。

1. **准备数据**：把 6 个数字放进数组 `a`，顺序是 `8 3 6 2 7 1`。
2. **两两比较**：让 `j` 从 0 开始，比较 `a[j]` 和 `a[j+1]`。如果前面的数比后面的大
   （比如 8 和 3），就把它们交换，让小的跑到前面。
3. **扫完一轮**：`j` 一直往后走，整排数字从前往后比一遍。这一轮结束后，最大的数 8
   一定会被“顶”到最右边的位置。
4. **重复多轮**：每一轮都比上一轮少看最后一个数，因为右边的位置已经排好了，不用再管。
5. **提前结束**：用 `swapped` 记录“这一轮有没有交换过”。如果一整轮一次都没交换，
   说明数字已经排好了，直接 `break` 结束，不用傻等循环跑完。
6. **打印结果**：最后用循环把数组输出，得到 `1 2 3 6 7 8`。

程序里每一轮的真实变化（和运行结果一致）：

```text
开始：  8 3 6 2 7 1
第1轮： 3 6 2 7 1 8   ← 最大的 8 冒到了最后
第2轮： 3 2 6 1 7 8   ← 7 冒到倒数第二位
第3轮： 2 3 1 6 7 8
第4轮： 2 1 3 6 7 8
第5轮： 1 2 3 6 7 8   ← 排序完成
```

## 2. 冒泡排序的基本思路

一句话：**反复比较相邻的两个数，如果顺序不对就交换它们，让大的数一点一点“冒”到后面去**
（就像水里的气泡往上浮），所以叫冒泡排序。

三个要点：

- **只比较相邻的两个元素**：每次拿 `a[j]` 和 `a[j+1]` 比，不管离得远的数。
- **一轮冒一个**：每一轮走完，当前没排好的部分里最大的那个数一定会被换到最右边，
  所以 n 个数最多只要 n-1 轮就能排好。
- **越排越少**：第 i 轮结束后，右边 i 个数已经就位，下一轮只需要看前面 n-i 个数。

它的缺点是慢：两层循环，大约要比较 n×n/2 次，n 越大越吃力，实际工程里数据量大时
一般用快速排序或 `std::sort`。但它的优点是简单、好懂、好写，很适合用来理解“排序”到底在干什么。

## 3. 改成从大到小排序要改哪里

**只需要改一个地方：内层循环里的那个比较符号。**

原来（从小到大）：

```cpp
if (a[j] > a[j + 1]) {   // 前面的大就交换 → 小的在前
```

改成（从大到小）：

```cpp
if (a[j] < a[j + 1]) {   // 前面的小就交换 → 大的在前
```

道理很简单：原来是把大的往后换，所以小的留在前面，结果是升序；现在反过来，把小的往后换，
大的留在前面，结果就是降序 `8 7 6 3 2 1`。

除了这个符号，其余代码一个字都不用动——不用改循环次数，也不用改 `n-1`、`n-i` 这些边界，
因为交换的逻辑是对称的，只是方向反了。运行后会得到：

```text
排序前：8 3 6 2 7 1
排序后：8 7 6 3 2 1
```
